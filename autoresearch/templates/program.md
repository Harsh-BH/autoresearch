# Task

Describe what you want the agent to improve here.

## Examples
- "Optimize the response time of the `/api/users` endpoint. Target metric: p50 latency in ms."
- "Improve test coverage of the `src/utils/` module. Target metric: percentage of lines covered."
- "Reduce the bundle size of the frontend build. Target metric: gzipped bundle size in KB."

## Notes
- The agent will explore the project, make changes, run benchmarks, and report metrics.
- Be specific about what "better" means (lower latency, higher coverage, etc.).
- You can specify files the agent should focus on or avoid.
